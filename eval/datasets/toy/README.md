# Toy dataset

16 short text items used only to check that the evaluation harness runs end to end (CI runs it on every push).

- **Human items:** public-domain passages written before 1900, quoted from memory (wording may differ slightly from the originals).
- **AI items:** written by an AI assistant for this file.
- **Short items:** one of each, to exercise the "Not assessed" path.

The set is far too small and too unrepresentative for any real claim, so numbers from it must never be quoted. Real datasets (RAID, MGTBench, the TOEFL bias set) arrive in M2 with held-out calibration splits.
